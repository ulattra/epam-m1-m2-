## Задания

### Задание 1: Реверс строки
Напишите метод, который переворачивает строку задом наперед.

> **Пример:**
> 
> Input: "Hello"
> 
> Output: "olleH"

---

### Задание 2: Проверка числа на палиндром
Напишите метод, который проверяет, является ли число палиндромом.
Число является палиндромом, если оно читается одинаково слева направо и справа налево.

> **Пример:**
> 
> Input: 121
> 
> Output: true
> 
> Input: 123
> 
> Output: false

---

### Задание 3: Вычисление факториала
Напишите метод для вычисления факториала числа.
n! = 1 × 2 × 3 × ... × n

> **Пример:**
> 
> Input: 5
> 
> Output: 120 (т.к. 5! = 1×2×3×4×5 = 120)

---

### Задание 4: Проверка числа на простоту
Напишите метод, который проверяет, является ли число простым.
Простое число делится только на 1 и само себя.

> **Пример:**
> 
> Input: 7
> 
> Output: true
> 
> Input: 10
> 
> Output: false

---

### Задание 5: Число Фибоначчи
Напишите метод для вычисления N-го числа Фибоначчи.
F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2)

> **Пример:**
> 
> Input: 10
> 
> Output: 55

---

### Задание 6: Подсчет гласных
Напишите метод, который подсчитывает количество гласных букв в строке.
Гласные: a, e, i, o, u (и их заглавные версии)

> **Пример:**
> 
> Input: "Hello World"
> 
> Output: 3

---

### Задание 7: Наибольший общий делитель (НОД)
Напишите метод для нахождения наибольшего общего делителя двух чисел.
Используйте алгоритм Евклида.

> **Пример:**
> 
> Input: 48, 18
> 
> Output: 6

---

### Задание 8: Проверка анаграмм
Напишите метод, который проверяет, являются ли две строки анаграммами.
Анаграммы — это слова, состоящие из одних и тех же букв.

> **Пример:**
> 
> Input: "listen", "silent"
> 
> Output: true
> 
> Input: "hello", "world"
> 
> Output: false

---

### Задание 9: Сумма цифр числа
Напишите метод, который вычисляет сумму всех цифр числа.

> **Пример:**
> 
> Input: 123
> 
> Output: 6 (т.к. 1 + 2 + 3 = 6)

---

### Задание 10: Поиск максимального элемента
Напишите метод для поиска максимального элемента в массиве целых чисел.

> **Пример:**
> 
> Input: [1, 5, 3, 9, 2]
> 
> Output: 9

---

### Задание 11: Проверка сортировки массива
Напишите метод, который проверяет, отсортирован ли массив по возрастанию.

> **Пример:**
> 
> Input: [1, 2, 3, 4, 5]
> 
> Output: true
> 
> Input: [1, 3, 2, 4, 5]
> 
> Output: false

---

### Задание 12: Удаление дубликатов
Напишите метод для удаления дубликатов из массива целых чисел.

> **Пример:**
> 
> Input: [1, 2, 2, 3, 3, 3]
> 
> Output: [1, 2, 3]
